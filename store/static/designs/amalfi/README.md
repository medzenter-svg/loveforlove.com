# Amalfi background assets

Place exactly one WebP background per approved stationery item in this directory. The editor and Playwright PDF generator load these files automatically by card id.

Design rules: ivory/cream paper, watercolor lemons, white flowers, greenery, refined gold details, no architecture, center kept visually clear for editable text. Background artwork must extend through the full 3 mm bleed area. Keep critical decorative details away from the trim edge so the composition does not look accidentally cropped.
